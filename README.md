# CRM-Immobilier

Version actuelle : **V2 orientée utilisateur** (agent immobilier), simple et rapide à utiliser.

- Pack complet prêt à copier-coller : `PACK_CRM_IMMOBILIER.md`
- Inclus : structure onglets, `Code.gs` unique, matching client-bien indépendant, dashboard terrain, guide d'installation.

## Démarrage rapide

1. Créez un Google Sheets vide.
2. Ouvrez **Extensions > Apps Script** et collez le contenu de `Code.gs`.
3. Rechargez le classeur puis utilisez le menu **📊 CRM Immobilier V4**.
4. Cliquez sur **🚀 Initialiser CRM V4** pour créer/configurer automatiquement les onglets.
